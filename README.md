# SyncWatch

Sync video play/pause/seek between two browsers in real time.
- **Mac (Brave):** Controller — your actions drive playback
- **iPad (Safari):** Receiver — automatically follows your play/pause/seek

---

## Step 1 — Deploy the Server (free, forever)

The server is a tiny Node.js WebSocket relay on Render's free tier.

1. Push the `server/` folder to a GitHub repo
2. Go to https://render.com → **New +** → **Web Service**
3. Connect your GitHub repo and use these settings:

   | Field | Value |
   |-------|-------|
   | Name | `syncwatch-server` |
   | Runtime | Node |
   | Build Command | `npm install` |
   | Start Command | `node server.js` |
   | Instance Type | **Free** |

4. Click **Deploy**. You'll get a URL like `https://syncwatch-server.onrender.com`

Your WebSocket URL will be: `wss://syncwatch-server.onrender.com`

> **Cold start note:** Render's free tier spins down after 15 min of inactivity. When you reconnect, it takes ~1 min to wake up. The auto-reconnect handles this automatically — just wait a moment.

### Local testing (same Wi-Fi)

```bash
cd server
npm install
node server.js
# URL: ws://YOUR_LOCAL_IP:3000
# Find your IP: ipconfig getifaddr en0
```

## Step 2 — Set Up the Mac (Controller)

1. Open Brave → `brave://extensions` → Enable **Developer mode**
2. Click **Load unpacked** and select the `extension/` folder
3. Click the SyncWatch icon → fill in:

   | Field | Value |
   |-------|-------|
   | Server URL | `wss://your-server.onrender.com` |
   | Room ID | Any shared name, e.g. `movie-night` |
   | Role | **Controller** |

4. Click **Save & Connect**, then reload your movie tab

---

## Step 3 — Set Up the iPad (Receiver)

No Xcode needed. Just use the bookmarklet:

1. Open the invite setup link generated by the Mac extension (which points to `/join?room=X&server=Y`).
2. The page is in Arabic and provides simple drag-and-drop instructions.
3. Drag the purple **🎬 SyncWatch** button to your Safari bookmarks bar (or onto the book/bookmarks icon).
4. Open your movie or video website, start playing, and tap the saved **🎬 SyncWatch** bookmark.

A purple badge will appear in the top-right corner confirming you are connected!

## How It Works

```
[Mac Brave]  →  play event + timestamp  →  [Render Server]  →  [iPad Safari]
```

- Only the Controller sends events; the Receiver only listens
- A 2-second seek threshold prevents tiny drift from triggering unnecessary seeks
- A 600ms lock prevents the Receiver's own play/pause events from echoing back
- WebSocket auto-reconnects every 3 seconds if the connection drops

## Troubleshooting

| Problem | Fix |
|---------|-----|
| Extension not triggering | Reload the movie tab after saving config |
| Video not found | Some sites load video late — wait a few seconds |
| iPad not receiving | Check both devices use the exact same Room ID and Server URL |
| Server slow to connect | Render free tier cold-starts after inactivity (~1 min) |
| `ws://` blocked on iPad | Safari requires `wss://` — use the Render URL |
